# Academic Minimal CV Website

Personal academic website for Samaneh Fathirashid, built with plain HTML and CSS for GitHub Pages.

## Publish with GitHub Pages

1. Make sure the repository is named `samanehfathirashid.github.io` and belongs to the GitHub account whose username is `samanehfathirashid`.
2. Upload `index.html` and `style.css` to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait a few minutes and visit `https://samanehfathirashid.github.io`.

## Before publishing

- Add the bachelor's graduation year and grade if desired.
- Add employment dates for Nikan Investment Company.
